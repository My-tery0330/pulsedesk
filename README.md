# PulseDesk

A calm second-screen dashboard for working on several projects at once.

- Project cards with repeating or daily check-in reminders
- One focus project at a time, with focus time tracked per day (Stats)
- Compact view for a second monitor, drag to reorder, English / Chinese interface
- Keeps the screen awake while in fullscreen (where the browser supports it)

## Your data

Everything is stored in your own browser (localStorage). Nothing is sent to a server,
and other visitors cannot see your projects. Data is per browser and per device:
use **Export** / **Import** at the bottom of the page to back it up or move it.
Clearing your browser's site data deletes it.
